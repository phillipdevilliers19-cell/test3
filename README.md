# RESET 66

A mobile-first 66-day habit reset app.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

This repository includes a GitHub Actions workflow that builds and deploys the Vite app to GitHub Pages. Vite is configured with a relative base so it works at `/test3/`.

Data is stored locally in the browser with localStorage; no backend is required for V1.
