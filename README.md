# RESET 66 — Arcade V3 Premium

This version is a full visual overhaul of the RESET 66 dashboard to match the high-detail arcade/game concept: desktop side rail, player/XP panel, journey map, mountain quest scene, task ring, mission board, reward chest and 3D arcade action dock.

## Deploy

Replace the files in the GitHub repository root with the contents of this package and commit to `main`. GitHub Actions will build and deploy it.

## Included

- Premium game-style dashboard
- 66-day quest map and checkpoints
- XP, levels, streaks and badges
- Arcade 3D controls
- Habit groups with unlimited sub-missions
- Individual task times and reminders
- Existing localStorage V3/V4 migration
- PWA manifest
- GitHub Pages Actions workflow
- Quest artwork asset

## Important

The artwork is decorative; all mission cards, progress, buttons and navigation remain real app controls. Existing RESET 66 progress is retained through the V4 storage migration.
